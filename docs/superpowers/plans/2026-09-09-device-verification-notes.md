## 結論: ポートフォワーディング仮説は棄却、ngrok を採用する

設計 第13節が「未検証」と明記していた仮説——**Chrome DevTools のポートフォワーディング経由なら、証明書もトンネルも無しに Android のカメラ AR が動く**——は、この環境では**成立しなかった**。

### 何が起きたか

`chrome://inspect/#devices` は端末をシリアル番号付きで検出した（`Offline #XXXXXXXXXXX`）。つまり **USB のデータ通信自体は成立しており、ケーブルの問題ではない**。しかし表示は最後まで次のままだった。

```
Pending authentication: please accept debugging session on the device.
```

端末側には「USB デバッグを許可しますか？」のダイアログが**一度も表示されなかった**。端末は「充電のみで接続しています」と通知するのみ。

### 試して駄目だったこと

1. 画面ロックを解除した状態で USB を抜き差し
2. 開発者向けオプションから「USB デバッグの許可を取り消す」→ 再接続
3. USB モードを「ファイル転送 / MTP」へ変更
4. USB デバッグのオフ→オン

いずれでも端末は `Offline` のままで、Android の Chrome からは `ERR_CONNECTION_REFUSED` になった。

**この時点で打ち切った。** 仮説の検証が目的であり、特定端末の USB 認証を通すことが目的ではない。

### 採用した方法: ngrok

`ngrok http 8080` でトンネルを張り、発行された `https://` URL を Android の Chrome で開いたところ、**カメラの許可を求められ、許可すると赤い箱が表示された**。端末を動かしても箱はその場に留まった。

USB 接続は不要。Wi-Fi でもモバイル回線でも動作する。

## L01 に書くこと

**ngrok 手順のみを書く。ポートフォワーディングは併記しない。** 初学者に選択肢を提示すると詰まるため。ただし読者は必ず「USB で繋げばよいのでは」と考えるので、**なぜ ngrok なのかを一行だけ添える**。

## つまずきポイントの一次資料

実際に踏んだ順に記録する。想像ではなく実測である点に価値がある。

### 1. URL の末尾スラッシュ

**症状:** `http://localhost:8080/lessons/01-first-ar` を開くと `404 Not Found`
**原因:** ローカルサーバがディレクトリ要求を 404 に変換していた
**対処:** サーバ側を 301 リダイレクトへ修正済み（`scripts/serve.mjs`）。読者は踏まなくなったが、**この欠陥はテスト 48 本とレビュー 4 回をすり抜け、実際に使った人間が最初に見つけた**。テストが純粋関数しか見ておらず、サーバを起動して普通に開く経路が未検証だったため。

### 2. USB デバッグの許可ダイアログが出ない

**症状:** `chrome://inspect` に端末は出るが `Offline / Pending authentication` のまま
**原因:** 端末側の許可ダイアログが表示されない
**対処:** この環境では解決できなかった。**8th Wall とも AR とも無関係な、Android 開発の入口の問題**である。だから L01 では USB を使わない。

### 3. ngrok の警告ページ

**症状:** ngrok の URL を開くと「You are about to visit ...」という画面が出て、AR に到達しない
**原因:** ngrok 無料版の仕様
**対処:** `Visit Site` を押す

### 4. トラッキングのずれ

**症状:** 端末を動かすと箱が少しずれる
**原因:** 8th Wall の SLAM は単眼カメラの映像から特徴点を追跡するため、カメラの画質・明るさ・被写体のテクスチャに精度が依存する
**対処:** **故障ではない。** L01 で事前に予告し、読者が「壊れている」と誤解しないようにする

## 未解決のまま残すこと

- **iOS は依然として未検証。** 端末が無い。「iOS 未検証」と明記する方針は変わらない
- ngrok は無料版でもアカウント登録が必要で、読者に登録を要求する。アカウント不要の代替（Cloudflare quick tunnel）は提示したが、利用者は ngrok を選択した。R2 以降で再検討の余地がある
