# 実機検証の手順（Task 8 後半）

**この作業だけは代行できません。** Android 端末の USB 接続と Chrome の設定が必要なためです。

所要時間はおよそ 10〜15 分。**うまくいかなくても構いません** — 「動いた」「動かなかった」のどちらでも、確定させることが目的です。

---

## 何を確かめるのか

> **Chrome のポートフォワーディング経由なら、証明書もトンネルも無しに Android のカメラ AR が動くのか？**

WebAR はカメラを使うため HTTPS を要求します。ただし `localhost` は例外で、ブラウザは安全な文脈（secure context）として扱います。Chrome の DevTools には PC のポートを Android 端末の `localhost` に転送する機能があり、**これを使えば端末側からは `localhost` に見えるはず**、というのが仮説です。

**成立すれば：** 読者は ngrok のアカウント登録も証明書の用意も不要になります。第 1 章が「HTML を 1 枚開くだけ」で完結し、参入障壁が大きく下がります。

**成立しなければ：** ngrok 手順に切り替えます。サンプル由来の設定（`config/webpack.config.js` の `allowedHosts` に `.ngrok-free.dev`）はこの前提で書かれているので、実績のある道ではあります。

どちらに転んでも設計は成立します。**未検証のまま教材を書き始めないこと**が目的です。

## 手順

### 1. サーバを起動する

**このワークツリーで**実行してください（元の `D:\xr\8thWallLearning` ではありません）。

```
cd D:\xr\8thWallLearning\.claude\worktrees\r1-course-foundation
npm run serve
```

`http://localhost:8080 で配信中` と出れば起動しています。**このターミナルは開いたままにしてください。**

> **注意:** 元リポジトリで `webpack-dev-server` が 8080 番を使っています（PID 54856）。ぶつかる場合は `npm run serve 8081` のように別ポートを指定し、以降の `8080` を読み替えてください。

### 2. 一時的にレッスンを公開対象にする

`lessons/manifest.json` の `01-first-ar` の `status` を `"draft"` から `"published"` に変えてください。ビルドが `dist/` に出力するのは `published` のものだけです。

変更したら、サーバを一度 Ctrl+C で止めて `npm run serve` を再実行します（起動時にビルドが走るため）。

**この変更は検証後に戻します。** 手順 6 で忘れずに。

### 3. まず PC で開く

PC の Chrome で次を開きます。

```
http://localhost:8080/lessons/01-first-ar/
```

**期待する結果:** カメラの許可を求められ、許可すると**赤い箱**が表示されます。

うまくいかない場合は F12 で開発者ツールを開き、Console のエラーを控えてください。ここで失敗するなら端末以前の問題です。

### 4. Android を接続する

1. Android 端末で **設定 → デバイス情報 → ビルド番号を 7 回タップ**して開発者オプションを有効化
2. **設定 → システム → 開発者向けオプション → USB デバッグ** をオン
3. USB ケーブルで PC に接続
4. 端末に「USB デバッグを許可しますか？」と出たら**許可**

### 5. ポートフォワーディングを設定する（ここが本題）

1. PC の Chrome で `chrome://inspect/#devices` を開く
2. **Discover USB devices** にチェックが入っていることを確認
3. 端末名が一覧に出ることを確認（出ない場合は USB ケーブルを挿し直す、別のケーブルを試す）
4. **Port forwarding...** ボタンを押す
5. **Enable port forwarding** にチェック
6. 左欄に `8080`、右欄に `localhost:8080` を入力して **Done**
7. **Android 端末の Chrome** で次を開く

```
http://localhost:8080/lessons/01-first-ar/
```

**確かめたいこと:**

- カメラの許可を求められるか
- 許可すると**赤い箱**が表示されるか
- 端末を動かすと箱がその場に留まるか（トラッキングが効いているか）

---

## 6. 終わったら戻す

`lessons/manifest.json` の `01-first-ar` を `"draft"` に戻してください。

このプロジェクトで `published` は「**Android 実機で動作を確認済み**」を意味します。検証が済んでも、L01 の本文（README）はまだ書かれていないので、公開対象にはしません。

サーバも Ctrl+C で停止してください。

## 私に教えていただきたいこと

次の 5 点だけ、分かる範囲で。

1. **PC（手順 3）で赤い箱は出ましたか？**
2. **Android（手順 5）で赤い箱は出ましたか？** — これが本題です
3. **端末の機種と Chrome のバージョン**（`chrome://version` で確認できます）
4. **途中で詰まった箇所**があれば、どこで何が起きたか
5. **エラーメッセージ**が出ていれば、その内容

4 番目が特に重要です。**あなたが詰まった箇所は、読者も必ず詰まります。** L01 の「つまずきポイント」は、ここで得た実際の記録から書きます。想像で書いたつまずきポイントは役に立ちません。
